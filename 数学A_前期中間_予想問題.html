数学A：前期中間テスト 予想問題

範囲：集合〜重複順列（全100点）

第1問： A = {1, 2, 3, 4}, B = {3, 4, 5, 6} のとき、A ∩ B を求めよ。 （5点）
第2問： Universal set U = {1～10}, A = {2, 4, 6, 8}, B = {1, 2, 3, 4, 5} のとき、(A ∪ B)' を求めよ。 （5点）
第3問： ある学校で、英語が得意な生徒は50人中30人、数学が得意な生徒は25人、両方得意な生徒は15人だった。英語または数学が得意な生徒は何人か？ （5点）
第4問： A = {x | x は自然数かつ x ≤ 6}、B = {2, 4, 6, 8} のとき、A ∩ B を求めよ。 （5点）
第5問： A = {a, b, c}, B = {b, c, d, e} のとき、A ∪ B を求めよ。 （5点）
第6問： 5人を1列に並べる方法は何通りか？ （5点）
第7問： 4人から2人を選んで座る席を決める方法は何通りか？ （5点）
第8問： 3人を円形に並べる方法は何通りか？ （5点）
第9問： 「MATH」の4文字を並べる方法は何通りか？ （5点）
第10問： 4人から2人を選ぶ方法は何通りか？ （5点）
第11問： 「LEVEL」の5文字を並べる方法は何通りか？ （5点）
第12問： 6人の中から3人を選んで順番に並べる方法は何通りか？ （5点）
第13問： 5人から3人を選ぶ組合せは何通りか？ （5点）
第14問： 「BANANA」の文字を並べるとき、異なる並べ方は何通りあるか？ （5点）
第15問： 「ABCD」のうち2文字を選んで順番に並べる方法は何通りか？ （5点）
第16問： 0, 1, 2の数字を使って3桁の整数を作るとき（先頭0不可）、何通りか？ （5点）
第17問： 赤青緑の3色から重複を許して4個のボールを選ぶ方法は何通りか？ （5点）
第18問： 5種類のアイスから、同じ種類を選んでもよいとして3個選ぶ方法は何通りか？ （5点）
第19問： 数字1〜9から重複なしで3桁の整数を作る方法は何通りか？ （5点）
第20問： 「AAB」の文字列を並べ替えるとき、異なる並べ方は何通りか？ （5点）
